# 沉浸车辆

当然，服务器是有载具的，不能合成

## 汽车
在本服，汽车是一种交通方式。
### 考取驾照
首先，来到郑州机铁站旁，阅读显示屏上面的须知，调整键位与CONFIG
调整完后，呼叫教练或op，教练会指引你上车
完成8个项目后，教练会对你评分
如果合格/过了，在屋子门前购买驾照（5000块）；
如果没过，听取教练的**（建议先在单人存档练习，避免不合格过多）**

### 买车
存钱完后，前往考取驾照的地方，旁边有个4S店
然后，呼叫op，op会问出问题，依次回答即可（谨慎选择卡车）
> ※车型、车颜色（可以先说颜色）、座椅型号与颜色
>
如有需要，可以将后面（除赛车）更换成箱子
配完车后，op会给你钥匙，妥善保管

### 开车
首先解锁车辆，打开车门，坐到座位上，点火，松开手刹，挂挡，注意进隧道时开灯，出隧道时鸣笛
定好目的地，看路牌，最好不超速（无限速时默认75），过弯时控制速度，避免冲出道路

#### 洗车

车在下雨天行驶时，车会沾上污垢
1.可以拿一个水桶，放在车架下中，等待几秒

2.等待下雨天，停车等待

3.在洗车站洗车，在SF、金林、威海、武汉、张家界装有

***4.把车开到河里，冲出来（不建议，危险）***

#### 发动机异响
当发动机出现异响，代表发动机里程达到500km，需要寻找op更换（免费）

#### HP
车辆的HP值一般为150（卡车250），当车辆HP值小于50时，发动机会冒黑烟，可使用加油站的修车包修复

#### 加油
在加油站里购买加油券（重庆特惠20），右击加油站，选择价格，等待出油（如果有油则跳过该步骤），再次右击加油站，开始加油

当显示：`Vehicle is full,disconnecting.`表示车辆加满油了，如果没有出现提示
，继续加油

## P菜单设置翻译
#### 第一页 RENDERING（渲染设置）  
| 选项 | 翻译 | 备注 |
| --- | --- | --- |
| renderHUD_1P | 第一人称显示 HUD | 开 = 第一人称屏幕上显示HUD |
| renderHUD_3P | 第三人称显示 HUD | 开 = 第三人称屏幕上显示HUD |
| fullHUD_1P | 第一人称完整 HUD | 开着会占更多屏幕，但更全 |
| fullHUD_3P | 第三人称完整 HUD | 同上，仅第三人称生效 |
| transpHUD_1P | 第一人称 HUD 透明化 | 开着 HUD 变半透明，不挡视线 |
| renderWindows | 渲染车窗玻璃 | 关掉能省性能 |
| freecam_3P | 第三人称自由视角 | 镜头独立，不跟车转 |
| renderBeams | 渲染车灯光束 | 夜景灯光效果 |
| brightLights | 高亮灯光 | 灯更亮更明显 |
| blendedLights | 混合柔光 | 灯光柔和 |
| lightsTransp | 灯光透明 | 灯罩半透明效果 |

**渲染模式**：Superfast（极速・性能最好画质差）／ Fast（快速・平衡）／ Slow（慢速・光影兼容最好，细节更多，帧率低）
