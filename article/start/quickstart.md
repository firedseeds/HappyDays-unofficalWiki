# 快速开始

*5 分钟完成账号设置、加入空间，并写下你的第一篇团队文档。*

欢迎加入 HappyDays。这篇指南不介绍所有功能，只带你完成三件最重要的事：**进来、写下、分享出去**。

> [!NOTE]
> **预计用时 5 分钟**
>
> 建议在桌面端浏览器中完成。你需要一个团队邮箱，以及管理员发出的邀请链接。

## 1. 登录并加入空间

1. **打开邀请链接**

   点击邮件或群聊中的邀请链接，使用团队邮箱登录。首次登录会自动创建账号，无需单独注册。

2. **确认你的角色**

   默认加入「HappyDays 团队」空间，角色为成员。角色决定你能否邀请他人和管理知识库，可随时由管理员调整。

3. **完善个人资料**

   在个人资料中填写昵称和职位。写清楚「你是谁、在做什么」，能帮助同事在评论中更快找到你。

## 2. 写下第一篇文档

进入「开始使用」空间，点击右上角的**新建文档**。不要从空白页开始纠结格式，先把你知道的写下来。

### 一个够用的文档骨架

标题写清楚问题 → 开头三行给结论 → 中间展开步骤 → 结尾留下维护者和更新时间。

### 先让它存在，再让它好看

标题、列表和代码块足以表达大部分内容。排版和配图可以在内容被验证之后再补。

试着用这个结构写一篇真实的文档，例如「本周发布流程」或「如何申请测试账号」：

```markdown
# 如何申请测试账号

结论：在「研发支持」知识库填写申请表，通常 1 个工作日内开通。

## 申请步骤
1. 打开申请表
2. 填写项目、环境与使用周期
3. 提交后在群里 @ 值班同学

## 维护者
- 最近更新：2026-10-18
```

## 3. 用快捷键提速

编辑器支持 Markdown 快捷输入和斜杠命令。记住下面这几个，就足够覆盖大部分写作场景。

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 搜索知识库 | `Ctrl / ⌘ + K` | 从任意页面唤起全局搜索 |
| 加粗选中文字 | `Ctrl / ⌘ + B` | 也可以输入 `**文本**` |
| 插入内容块 | `/` | 输入 / 后选择标题、表格、代码块等 |
| 保存草稿 | `Ctrl / ⌘ + S` | 自动保存已开启，手动保存更安心 |
| 发布文档 | `Ctrl / ⌘ + Enter` | 发布前可以设置可见范围 |

> [!WARNING]
> **发布前检查可见范围**
>
> 草稿仅自己可见；发布到空间后，空间成员可以查看。选择「互联网可见」前，请确认文档不含内部链接、客户信息或未公开数据。

## 4. 发布与分享

点击右上角的**发布**，选择目标知识库和可见范围。发布后，你可以复制页面链接，或使用「分享」生成带权限的有效链接。

- 标题能让同事一眼判断内容是否相关
- 开头写清结论和适用对象
- 至少添加一个标签，方便横向检索
- 指定一位维护者，并写明如何联系

发布不是结束。被引用、被评论、被更新，才是一篇文档真正开始工作的时候。
